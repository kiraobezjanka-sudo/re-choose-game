# Протокол «Эхо»

Небольшая оригинальная диалоговая survival-horror игра. Игрок встречает заражённого доктора Лиана Вейла в заброшенной подземной лаборатории и решает, как получить ключ-карту или найти иной выход.

В игре шесть завершённых маршрутов к трём финалам: мирная передача ключ-карты, бегство от утратившего контроль учёного и раскрытие тайны проекта «Эхо».

## Запуск

Игра не требует зависимостей. Откройте `index.html` через локальный статический сервер, например:

```powershell
python -m http.server 4173
```

Затем откройте `http://localhost:4173`.

Для каждой ветки с Pull Request автоматически публикуется изолированное GitHub Pages-превью. Ссылка появляется в обсуждении PR после успешной проверки.

## Проверка

```powershell
npm test
npm run build
```

Управление выполняется мышью, касанием или клавиатурой. `P` и `Escape` включают и снимают паузу во время диалога. После любого финала доступна кнопка перезапуска.

Визуал, названия, сюжет и персонажи созданы специально для этой игры. Сторонние изображения, музыка и материалы других игровых серий не используются.
