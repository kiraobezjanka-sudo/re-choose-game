# Архитектура и проверка

## Архитектура и файлы

- `game-model.js` — единственный источник состояния и переходов.
- `game.js` — DOM-отрисовка и обработка ввода.
- `audio.js` — оригинальный процедурный эмбиент, звуки выбора и управление звуком.
- `styles.css` — оригинальная процедурная сцена без внешних ассетов.
- `tests/game-model.test.mjs` — тесты маршрутов, паузы и перезапуска.
- `scripts/build.mjs` — статическая сборка проекта в `dist/`.

## Локальные команды

- `npm test` — запустить автоматические тесты.
- `npm run build` — собрать статическую версию в `dist/`.

## Проверка в браузере

- Пройти все шесть маршрутов и увидеть три финала.
- Проверить паузу и продолжение игры.
- Проверить чистый перезапуск после финала.
- Проверить звук обычных кнопок и отдельный звук кнопок реплик.
- Проверить ширины 1440 px, 390 px и минимальную ширину 320 px.
- Убедиться в отсутствии горизонтальной прокрутки и ошибок консоли.
