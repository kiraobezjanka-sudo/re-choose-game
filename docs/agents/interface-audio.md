# Интерфейс и звук

## Управление

- Основное управление — четыре понятные кнопки выбора.
- Все действия одинаково работают мышью, клавиатурой и касанием.
- `P` и `Escape` переключают паузу во время активной сцены.
- После финала доступна кнопка начала новой игры.

## Доступность и адаптивность

- Интерактивные элементы имеют заметное состояние фокуса.
- Интерфейс остаётся читаемым начиная с ширины 320 px.
- Анимации учитывают `prefers-reduced-motion`.
- На мобильном экране не должно быть горизонтальной прокрутки или недоступных кнопок.

## Звук

- Весь звук создаётся средствами Web Audio API без внешних аудиофайлов.
- Аудиоконтекст запускается только после действия пользователя для совместимости с мобильными браузерами.
- Кнопка звука доступна во всех игровых состояниях.
- Скрытая вкладка приостанавливает аудиоконтекст.
- Кнопки реплик используют отдельный тревожный звук выбора.
- Остальные кнопки используют обычный интерфейсный щелчок.
