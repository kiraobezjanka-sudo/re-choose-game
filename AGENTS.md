# Протокол «Эхо»

## Концепция и границы

Это одностраничная оригинальная браузерная survival-horror игра на русском языке. Игрок ведёт напряжённый разговор с заражённым доктором Лианом Вейлом в секторе N-17. Проект не использует персонажей, названия, логотипы, музыку или изображения существующих игровых серий и не требует сети, сервера или учётной записи.

## Правила, которые нельзя ломать

- Диалоговое дерево содержит не более семи узлов.
- Первый диалог предлагает ровно четыре утверждённых действия: спокойный разговор, аптечка, ложь о спасателях и угроза оружием.
- Каждое начальное действие заметно меняет доверие, заражение, текст последствия и маршрут.
- Все маршруты завершаются одним из трёх финалов: мирная ключ-карта, превращение и бегство, секрет лаборатории и скрытый путь.
- После финала новая попытка должна начинаться без истории и значений прошлой попытки.
- Статусы модели: `idle`, `running`, `paused`, `finished`. В паузе решения не принимаются.

## Управление и доступность

Основное управление — видимые кнопки, одинаково работающие с мышью, клавиатурой и касанием. `P` и `Escape` переключают паузу во время активной сцены. Интерактивные элементы обязаны иметь заметный фокус; интерфейс должен сохранять читаемость от 320 px и учитывать `prefers-reduced-motion`.

Звук создаётся только средствами Web Audio API и запускается после пользовательского действия для совместимости с мобильными браузерами. Кнопка звука должна оставаться доступной во всех игровых состояниях; скрытая вкладка приостанавливает аудиоконтекст.

## Технология и структура

- `game-model.js` — единственный источник состояния и переходов.
- `game.js` — DOM-отрисовка и ввод.
- `audio.js` — оригинальный процедурный эмбиент, щелчки и управление звуком.
- `styles.css` — оригинальная процедурная сцена без внешних ассетов.
- `tests/game-model.test.mjs` — проверка маршрутов, паузы и перезапуска.
- `scripts/build.mjs` — статическая сборка в `dist/`.

## Проверка

Запустить `npm test` и `npm run build`. В браузере проверить начало, все шесть маршрутов, три финала, паузу, перезапуск, ширину 1440 px, мобильную ширину 390 px, отсутствие горизонтальной прокрутки и ошибок консоли.

## Git и публикация

Рабочие ветки используют префикс `codex/`. Правила автоматического GitHub Pages-превью описаны в `docs/agents/preview.md`. Публикация основной версии, слияние и изменение доступа требуют отдельного разрешения пользователя. Локальное превью можно запускать статическим сервером из `dist/`.
