# Протокол «Эхо»

Одностраничная оригинальная браузерная survival-horror игра о разговоре с заражённым учёным в заброшенной подземной лаборатории.

## Карта проектных правил

Перед изменением соответствующей части проекта прочитайте связанный документ:

- [Концепция и границы](docs/agents/concept.md) — оригинальность, платформа и ограничения проекта.
- [Игровой контракт](docs/agents/gameplay.md) — дерево диалогов, состояния и обязательные финалы.
- [Интерфейс и звук](docs/agents/interface-audio.md) — управление, адаптивность, доступность и Web Audio API.
- [Архитектура и проверка](docs/agents/architecture-testing.md) — назначение файлов, команды и браузерный чек-лист.
- [Pull Request и превью](docs/agents/preview.md) — локальный порядок работы, ветки и GitHub Pages.

## Общие правила

- Не дублируйте правила из тематических документов в этом файле.
- Все изменения сначала реализуйте и проверяйте локально.
- До явного одобрения пользователя не выполняйте commit, push и не создавайте или обновляйте Pull Request.
- Не объединяйте Pull Request и не публикуйте основную версию без отдельного явного запроса.
